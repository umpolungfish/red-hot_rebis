Every demo runs, and the arrangement engine is reachable

Six of the fourteen demos died on import against names their modules do not define,
and had done for long enough that the API had moved out from under them. The B4
lattice demo asked for a class that does not exist and now builds the same display
from the nucleotide map and the codon type; the Belnap demo asked for a state wrapper
and now prints the four values, both tables and the two negation fixed points from
the kernel's own functions; the material forge demo asked for a constant and now
calls the function that returns the designs; the serpentrod demo lacked its output
helpers entirely and read the residue assignment from the wrong module; the catalytic
site demo named a lattice class, a translation pipeline and an amino acid table that
are all called something else.

The arrangement engine exposed nothing from its package, so a census read it as empty
while all nine of its modules imported cleanly. Every engine is reachable from the
package now, as the other domains are.

Wobble takes two values, and the demo was passing one.
