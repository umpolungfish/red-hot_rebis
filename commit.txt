Every module in the repository runs

The last failures were mostly collateral: a patch script from an older generation
inserts its import at the first line of a parenthesised import rather than after its
closing bracket, which is a syntax error, and it had done it twice. Those older
generations refuse import now, as the current one already documents the trap in a
comment.

The rest were plain: a module using numpy without importing it, two calling the
printing helpers without importing them, and several that only failed because the
sweep before them had truncated the dataset generators.

The imscription agent reached for an outside account and could not run without one.
Its default lane is this project's own inference now, through the ask binary, with no
key and nothing external; the other providers remain available by name.

The tool demo asked the catalog for entries that are not in it and reported the miss
as its output. It names entries that exist.
