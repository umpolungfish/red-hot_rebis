Eleven modules that could not run, and the patch that kept undoing one of them

A spent patch script rewrote the retrosynthetic pipeline every time it ran, from a
copy it reconstructed line by line, which is how an old revision with two methods
written bottom to top kept coming back after I repaired the file. It writes nothing
now; its own guard already proved the change is in place.

The rest were each a name that had moved: a design importing the therapeutics package
by bare name, two plastic eaters importing a kernel module and a sibling design by
bare name, an agent importing its tool by bare name and then asking for a class the
tool does not export, a tool importing the molecular domain that the grammar tree
retired on purpose and recorded as superseded by this repository, a command wiring a
parser to a function defined sixty lines below it, a structure comparison using numpy
without importing it, a demo printing before importing its helpers, and a ligand
sweep writing per-protein files into a directory it never created.

That sweep in process yields tens of thousands of ligands where the version that
scraped a subprocess reported a few hundred, because the scraper counted only what it
had not already seen and discarded the rest.
