# Restructuring an over-fused word to closure

Insertion does not close an F word (01): adding forks balances counts but
leaves fuses unmatched where no fork precedes them under cyclic pairing. The
balanced rule (02) closes only because fork, work, fuse are ordered from the
start. The open problem is the reorder: take the marks of an F word and
arrange them so every fork precedes the work its fuse closes.
